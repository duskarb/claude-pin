문장을 선택하고, 오른쪽 보드로 끌어보세요.

아래 화면은 이미지가 아니라 실제로 동작합니다. 답변의 문장을 선택해 오른쪽으로 끌어 보세요. 터치 화면에서는 문장을 선택하면 나오는 핀 버튼을 누르면 됩니다.

  1. Capture 답변에서 문장을 선택해 끌어다 놓기
  2. Organize 보드를 넓혀 검색하고 댓글 달기
  3. Return 핀의 세션 링크로 원래 문장에 돌아가기
+ Sonnet 4.5

예시 응답만 나오는 프로토타입입니다. 실제 모델에 연결되어 있지 않습니다.
