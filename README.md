# Claude Pin

AI 대화에서 문장을 드래그해 핀하고, 핀에서 원래 대화의 그 문장으로 돌아가는 기능의 UX 케이스 스터디와 동작 프로토타입입니다.

한 페이지를 스크롤하면 문제 정의부터 리서치, 구조, 설계 과정, 프로토타입, 컴포넌트까지 순서대로 볼 수 있습니다.

## 프로토타입에서 해 볼 수 있는 것

- **Capture**: 답변의 문장을 선택해 끌면 핀 보드가 들어오고, 놓으면 핀이 됩니다. 문장을 선택하면 나오는 "핀하기" 버튼으로도 됩니다.
- **Organize**: 보드를 넓혀 검색하고, 세션별로 묶어 보고, 댓글을 달고, 삭제합니다.
- **Return**: 핀의 세션 링크를 누르면 그 세션의 원래 문장으로 이동합니다.
- 케이스 스터디 본문의 문장도 같은 방식으로 핀할 수 있습니다.

대화는 예시 응답이며 실제 모델에 연결되어 있지 않습니다. 핀은 브라우저의 localStorage에만 저장됩니다.

## 실행

빌드 과정이 없습니다. `index.html`을 브라우저로 열거나 정적 서버로 띄웁니다.

```
npx serve .
```

## 구성

- `index.html`: 케이스 스터디 본문과 프로토타입 마크업
- `styles.css`: 토큰과 스타일
- `app.js`: 선택, 드래그, 핀 저장, 보드, 세션 이동
