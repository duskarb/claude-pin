# Claude Pin

AI 답변에서 필요한 문장만 끌어서 꽂아 두고, 언제든 그 문장이 나온 대화로 돌아가는 경험을 제안하는 컨셉 프로토타입입니다.
여남규의 KAIST ID307 개인 UX 프로젝트이며 Anthropic과 무관합니다.

**Live:** https://claude-pin.vercel.app

## 무엇을 해 볼 수 있나

- 답변에서 문장을 드래그해 선택하고, 오른쪽 핀 보드로 끌어 꽂기 (또는 「핀」 버튼)
- 핀 보드 안에서 순서 바꾸기, 메모 달기, 검색, 크게 보기로 정리
- 핀 카드를 눌러 그 문장이 나온 원래 대화로 돌아가기
- 브라우저 창을 좁히면 모바일 버전: 길게 눌러 선택, 사이드 메뉴의 ‘메모’, 밀어서 지우기

데모의 대화는 여남규를 소개하는 예시 답변이며, 실제 AI 모델은 연결되어 있지 않습니다. 핀은 브라우저 localStorage에 저장됩니다.

## 파일 구성

| 파일 | 역할 |
| --- | --- |
| `index.html` | 화면 골격, 아이콘 세트(SVG symbol) |
| `app.css` | 디자인 토큰과 전체 스타일 |
| `app.js` | 선택·드래그·핀 보드·원문 복귀·모바일 동작 |
| `intro.js` | 첫 방문 안내 카드와 애니메이션 |
| `content.js` | 대화 내용과 미리 꽂힌 핀 |
| `favicon.svg` | 파비콘 |

빌드 과정은 없습니다. 아무 정적 서버로 열면 됩니다.

```sh
python3 -m http.server 8000
```

## 디자인 시스템 요약

- **글자:** 크기 11 · 12 · 13 · 14 · 15 · 16 · 17 · 24, 굵기 400 본문 · 500 동작 · 600 제목 · 700 라벨. 본문은 Pretendard, 로고만 Source Serif 4 Medium(Claude 검정 + Pin 주황). 본문과 UI에는 세리프를 쓰지 않습니다.
- **아이콘:** 24 그리드, 키라인 사각 16 / 원 17, 모서리 r2.5, 크기 14 · 18 · 20, 선 굵기 1.75 (동작 라벨 옆과 작은 아이콘은 2).
- **드래그:** 문장 드래그, 핀 순서 바꾸기, 안내 애니메이션 모두 같은 주황색 알약 하나와 삽입선.
- **상자:** 텍스트는 상자에 넣지 않고 색과 굵기로 위계를 나눕니다. 상자는 끌어서 옮기는 것과 핀 보드에만 씁니다.
